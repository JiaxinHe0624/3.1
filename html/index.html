About the App

StudyTrack is a web based study task management system built for students who are enrolled in several courses at the same time. Most people start a semester with a paper list or a spreadsheet, and both become hard to keep accurate once three or four assessments land in the same week.

The application keeps one central list of study tasks. Each task records a title, the course it belongs to, a due date, a short description and any extra notes. Tasks can be added, edited or deleted from a single page, and the list is sorted by due date so the most urgent work is always at the top.

Key features

  • Create a study task with a course code, course name, due date and notes.
  • Update an existing task when a deadline moves.
  • Delete a task only after a confirmation dialog.
  • View every task in one table, with overdue items highlighted.
  • Validation rejects empty required fields and impossible dates.
  • A login gate keeps the task list private on a shared computer.

I used to plan my semester in a paper notebook: every assessment was written down, split into smaller blocks and ticked off once finished. The problem was that the notebook could not sort anything, so in the weeks when four courses were due at once I would constantly re-copy the same list. StudyTrack is the version of that notebook I actually wanted: the same tasks, sorted by due date, with anything overdue shown in red.
